# Recipe Book

A simple, interactive web app where you can pick your favorite dish and instantly view its recipe,i complete with a video guide!

 Live Demo: [https://aadyagoyal0810-alt.github.io/Recipe-Book/](https://aadyagoyal0810-alt.github.io/Recipe-Book/)
---

## About
Recipe Book lets you select a dish from a dropdown menu and view step-by-step instructions along with a helpful cooking video. Built with plain HTML, CSS, and JavaScript — no frameworks, no dependencies.

## Features
- Dropdown menu to choose from multiple dishes
- Video demonstration for each recipe
- Clean, simple, responsive interface
- Fast — pure HTML/CSS/JS, no build steps required

## Recipes Included
- Pasta
- Pizza
- Lasagna
- Burrito Bowl
- Brownie
- Avocado Toast

## Built With
- HTML5 — structure
- CSS3 — styling
- JavaScript — dish selection logic and dynamic content

## Project Structure
```
Recipe-Book/
├── recipe.html      # Main HTML file
├── recipe.css       # Styling
├── recipe.js        # Dish selection logic
├── recipes.js       # Recipe data
├── *.mp4            # Recipe demonstration videos
└── *.png            # Cover and background images
```
